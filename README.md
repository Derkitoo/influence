## 📱 Fonctionnalités Principales

### 1. Les 7 Principes Fondamentaux de Robert Cialdini
* 🎁 **La Réciprocité** (dons non sollicités, technique du rejet-retrait / concession réciproque).
* 🔄 **L'Engagement et la Cohérence** (pied-dans-la-porte, écrit et engagement public, amorce / *low-balling*).
* 👥 **La Preuve Sociale** (ignorance pluraliste, effet témoin, principe de similarité).
* ❤️ **La Sympathie** (effet de halo, compliments, coopération / buts supra-ordonnés de Robbers Cave).
* 🎖️ **L'Autorité** (soumission aveugle de Milgram, symboles de statut, audit de compétence).
* ⏳ **La Rareté** (peur de la perte, réactance de Brehm, rivalité pour les ressources).
* 🛡️ **L'Unité (7ᵉ principe)** (sentiment du « Nous », métaphores tribales, co-création via conseil vs avis).

### 2. Écosystème Comportemental & 4 Modules UX Avancés
* **Module A : Onboarding & Choix par Défaut**
  * *Option par défaut bienveillante* (**Richard Thaler**) : sélection du rythme optimal par défaut.
  * *Pouvoir du Gratuit* (**Dan Ariely**) : passe 30 jours offert sans carte bancaire requise.
  * *Déclencheur Externe* (**Nir Eyal**) : notification relationnelle d'activation immédiate.
* **Module B : To-Do Délibérative Système 2 & Focus**
  * *Ralentissement cognitif Système 2* (**Daniel Kahneman**) : forcer les intentions de mise en œuvre (*Où ? Quand ? Premier micro-pas de 2 min*).
  * *Capital de Clarté (Stored Value)* (**Nir Eyal**) : capitalisation de points décisionnels à chaque tâche complétée.
  * *Sprint de Focus Collectif* (**Cialdini / Thaler**) : session de Deep Work collective de 90 min en temps réel.
* **Module C : Moteur de Notifications Empathiques**
  * *Étiquetage Émotionnel* (**Chris Voss**) : désamorcer la culpabilité (*« Il semble que cette tâche soit devenue lourde... »*).
  * *Récompenses Variables* (**Nir Eyal**) : éveil de curiosité intellectuelle sans spam.
* **Module D : Tunnel d'Achat Éthique & Effet de Leurre**
  * *Ancrage Extrême* (**Chris Voss**) : comparaison de valeur avec un coaching individuel (180 €/h).
  * *Effet de Leurre Asymétrique* (**Dan Ariely**) : grille à 3 niveaux mettant en évidence la formule optimale.
  * *Sortie Respectueuse* (**Chris Voss**) : question calibrée sans Dark Pattern.

### 3. Outils Pratiques & Auto-Défense
* 🎯 **Simulateur de Diagnostic de Situations** : décryptage en 1 clic de 8 cas réels (négociation salariale, concession auto, fausse urgence e-commerce, Bon flic / Mauvais flic...) avec riposte prête à copier.
* 🛡️ **Bouclier Anti-Manipulation** : signaux viscéraux d'alarme (estomac, cœur, adrénaline) et 6 formules verbales de contre-attaque.
* 🧪 **Bibliothèque des Grandes Expériences** : Milgram, Langer, Latané & Darley, Sherif, etc.
* 📊 **Test de Vulnérabilité Psychologique** : questionnaire mesurant votre Indice Global d'Immunité avec plan d'action personnalisé.

## 🚀 Installation PWA (Progressive Web App)

L'application est **100% installable** sur smartphone (iOS, Android) et sur ordinateur (Windows, Mac, Linux) :
1. Ouvrez [https://derkitoo.github.io/influence/](https://derkitoo.github.io/influence/) dans Chrome, Edge ou Safari.
2. Cliquez sur la bannière **« Installer l'application »** ou sur l'icône de partage / installation du navigateur.
3. L'application fonctionne **entièrement hors-ligne** grâce à son Service Worker autonome !

## 💻 Développement Local

```bash
# Cloner le dépôt
git clone https://github.com/Derkitoo/influence.git
cd influence

# Lancer un serveur local
python -m http.server 5500
```
Ouvrez ensuite `http://localhost:5500` dans votre navigateur.
